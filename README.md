# 💰 Family Expense Tracker

An Android app to track family expenses using Google Sheets as a live backend.

## 📋 Project Status
🚧 In Development

## 🎯 Features
- Google Sheets as live backend (multi-user)
- Multiple accounts support
- Add, Edit, Delete transactions
- Transfer between accounts
- Search transactions by description
- Free & personal use (no Play Store)

## 🛠️ Tech Stack
- **Language:** Kotlin
- **UI:** Jetpack Compose
- **Backend:** Google Sheets API v4
- **Auth:** Google OAuth 2.0
- **Architecture:** MVVM
